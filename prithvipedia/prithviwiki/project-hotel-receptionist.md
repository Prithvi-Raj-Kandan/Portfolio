# Project: Hotel_Receptionist

## What It Is
An agentic AI voice receptionist for hotel workflows including customer inquiries and booking-related operations. [source: prithvipedia/rawdata/.extract/Prithvi-Raj-Resume.txt]

## Core Pipeline
As described in internship report and resume context:
- STT via Deepgram.
- LLM reasoning with LangChain agent orchestration.
- Context memory via LangChain memory module.
- Database-backed hotel context via MongoDB.
- Output parsing for speech-friendly responses.
- TTS via ElevenLabs.
[source: prithvipedia/rawdata/.extract/Prithvi-Raj-Resume.txt]
[source: prithvipedia/rawdata/.extract/Internship_Report(Ai_Receptionist)final P02 (1).txt]

## Backend and Frontend
- Backend with FastAPI unified endpoint flow.
- Browser frontend with audio capture and playback loop.

### Codebase Shape During Build
- Compact full-stack repo with core files only: `main.py`, `lcmdb.py`, `app.js`, `index.html`, `styles.css`, and `requirements.txt`.
- This indicates a focused single-app architecture rather than a large multi-package repo.
